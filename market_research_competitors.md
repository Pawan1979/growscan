### 🔥 Feature 1: Split-Cart Optimizer (NOBODY HAS THIS)

> *"What if I can save more by ordering 8 items from Zepto and 4 items from Blinkit?"*

```
User adds 12 grocery items to GrocScan cart
↓
GrocScan calculates:

OPTION A — Single platform:
  Blinkit: ₹1,240 + ₹20 fee = ₹1,260 (18 mins)
  Zepto:   ₹1,198 + ₹15 fee = ₹1,213 (12 mins) ← Single best

OPTION B — Split cart (2 orders):
  8 items from Zepto:    ₹742 + ₹15 fee = ₹757
  4 items from Blinkit:  ₹398 + ₹20 fee = ₹418
  TOTAL = ₹1,175 ← Saves ₹38 but 2 orders

💡 GrocScan Recommendation:
  "Order from Zepto — saves ₹47 vs Blinkit, arrives in 12 mins"
```

This feature makes GrocScan **10x more useful** than every competitor.

### 🔥 Feature 3: True Final Price with ALL Fees

> *"Every app shows sticker price. I want what I actually PAY."*

**Fees GrocScan must include:**

| Fee Type | Typical Amount | Who charges it |
|---|---|---|

| Handling fee | ₹5–15 | Varies by platform |
| Small cart charge | ₹10–25 | If order < ₹99–199 |
| Rain/surge fee | ₹15–45 | During bad weather or peak |
| Delivery charge | ₹0–49 | Varies by subscription |

```
WITHOUT GrocScan (what others show):

  Blinkit: ₹27 + ₹5 platform + ₹10 handling + ₹20 delivery = ₹62 total
  Zepto:   ₹26 + ₹6 platform + ₹0 handling  + ₹0 (Zepto Super) = ₹32 total ← WIN
```
